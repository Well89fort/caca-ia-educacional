# caca-ia-educacional
O "Caça-IA" é um jogo web educacional de extensão universitária para alunos do ensino fundamental e médio. A ferramenta gamificada promove o letramento algorítmico ao desafiar os jovens a investigar produtos reais, diferenciando o que possui Inteligência Artificial do que é apenas automação ou discurso publicitário.
